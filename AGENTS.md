# AGENTS.md — правила работы (Karpathy-принципы)

## 1. Думай до кода
- Не делай молчаливых допущений. Если неясно — задай вопрос или перечисли допущения.
- Сначала изучи существующий код (поиск, чтение), потом предлагай план.
- Если есть несколько подходов — назови их и обоснуй выбор.

## 2. Простота прежде всего
- Минимум кода, решающий задачу. Никаких «на вырост» абстракций и настроек.
- Нет новых зависимостей без необходимости; JS-библиотеки только вендорены в Resources.
- Если решение можно уместить в меньше строк — перепиши.

## 3. Хирургические правки
- Трогай только то, что нужно для задачи. Никакого попутного рефакторинга/форматирования.
- Стиль кода соседних файлов сохраняй. Заметил чужую проблему — упомяни, не чини.
- Убирай только тот мусор, который создали твои изменения.

## 4. Целеориентированное исполнение
- Превращай задачу в проверяемый критерий (тест, сборка, ручная проверка) до начала.
- Работай циклом: правка → сборка/тест → проверка критерия. Не объявляй «готово» без доказательства.
- Каждый шаг заканчивается: что сделано, чем проверено, что осталось.

## Проектные ограничения
- Платформа: macOS, Apple Silicon (arm64), Xcode; сборка `xcodebuild`, workspace `MacDown 3000.xcworkspace`.
- Не менять Hoedown/Prism внутренности, если задачу можно решить в слое шаблона/скриптов.
- Все коммиты маленькие, одна цель на коммит.

## Build (проверено 2026-11-01; статус: ЗЕЛЁНАЯ)
- Сборка: `xcodebuild -workspace "MacDown 3000.xcworkspace" -scheme MacDown -configuration Debug -destination 'platform=macOS,arch=arm64' build` → BUILD SUCCEEDED, 0 ошибок (коммит cd6ad88).
- Тесты: та же команда с `test` вместо `build` (гоняет MacDownTests; обязательно добавлять `CODE_SIGNING_ALLOWED=NO` — без подписи CodeSign CLI-утилиты `macdown-cmd` падает в окружении без сертификата).
- Схема `MacDown` — единственная для приложения (`MacDown 3000.xcodeproj/xcshareddata/xcschemes/`; рядом только `MacDownUITests`).
- Предусловия (выполнены): `git submodule update --init` (Prism) + brew-Ruby 4.0 (`/opt/homebrew/opt/ruby/bin`) + `bundle install` (cocoapods 1.16.2) + `bundle exec pod install` (9 подов). Системный Ruby 2.6 не годится (нет bundler 2.7.2).
- Минимум macOS поднят 11.0→12.0 (требует Xcode 27.2): `project.pbxproj` (12 мест), `Podfile`, `Podfile.lock` (checksum), `README.md`, `docs/`. `@available(macOS 11.0)`-гарды и фикстуры `test_update_appcast.py` оставлены сознательно.
- Предупреждение про `IDESimulatorFoundation/CoreSimulator` не фатально.
